# Amophor — Protótipo frontend

Abra `index.html` no navegador ou use a extensão Live Server do VS Code.

## Recursos
- Projetos independentes
- Espaços de texto, desenho e mistos
- Desenho com caneta, borracha, cores e espessura
- Importação de imagens para a tela
- Salvamento automático via localStorage
- Renomear e excluir projetos

## Limitações desta primeira versão
Os dados ficam apenas no navegador e dispositivo atual. O armazenamento local é limitado, especialmente para imagens. Não há login, sincronização na nuvem, pastas aninhadas, movimentação de imagens no canvas nem exportação de backup. Para uso sério, o próximo passo é implementar IndexedDB, backups e ferramentas avançadas de canvas.
